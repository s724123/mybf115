# ADR-0001: 菜單項目版本化儲存（方案A）

菜單修改需要保留完整的版本歷史以供追溯，且 `order_items` 需能指向特定版本。選擇了**方案A（業務層版本化）**：每次修改建立一個新版本 row，保留所有歷史資料。替代方案（方案B：in-place update + 快照）已被捨棄，因為無法滿足「查看所有修改前的菜單版本」的業務需求。

**Status**: accepted

**考慮的選項**:
- **方案A（業務層版本化）**：`menu_items` 每個版本獨立一行，`order_items.menuItemId` FK 指向特定版本
- **方案B（實作層快照）**：`menu_items` 原地更新，`order_items` 存完整快照 — 被拒絕，因為無法查詢版本歷史

## 訂單提交行為

訂單送出時驗證所有 `order_items` 參考的 `menuItemId` 是否仍為 `isCurrentVersion = true`。
若任一項目已不是最新版本，拒絕提交並提示哪些項目已更新。

_拒絕自動更新（已考慮但被否決）：自動更新到最新版本可能導致顧客結帳時價格與預期不符，
容易引發客訴。_ 讓顧客重新加入購物車可確保明確定價。
